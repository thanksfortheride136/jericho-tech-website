Track 1

Guided Data Analysis

A guided, no-code option for traditional laboratory, survey and observational research projects that require data analysis.

Primary Tools Data Classroom
1 Collect or Import Data

Enter data collected from an experiment, survey or observation, or import an existing dataset.

2 Clean and Validate Data

Check for missing values, duplicate records, inconsistent labels, incorrect units and values that may be inaccurate.

3 Prepare and Transform Data

Organize variables, group categories, create calculated values and prepare the dataset for analysis.

4 Explore Data

Examine descriptive statistics, distributions, patterns, group differences and unusual observations.

5 Visualize Data

Create graphs that clearly represent the variables, comparisons and relationships within the data.

6 Analyze Data

Use statistical methods that are appropriate for the research question and type of data.

7 Model if Appropriate

Build a statistical or predictive model only when it directly supports the research question.

8 Evaluate and Interpret

Interpret the findings, evaluate the strength of the evidence and identify limitations.

9 Communicate and Document

Present the methods, data, visualizations, analysis, conclusions and limitations of the project.

Track 2

Computational Data Science

A Python based data science track for larger datasets, automation and reproducible computational workflows.

Primary Tools Python, JupyterLab, pandas, NumPy, Matplotlib / Seaborn, scikit-learn
1 Collect or Import Data

Load collected or existing research data into Python and JupyterLab.

2 Clean and Validate Data

Use Python to identify missing values, duplicates, incorrect data types, invalid entries and inconsistent units.

3 Prepare and Transform Data

Filter observations, combine datasets, create variables, encode categories and prepare features for analysis.

4 Explore Data

Use summaries and exploratory analysis to understand distributions, relationships and possible data problems.

5 Visualize Data

Create reproducible data visualizations using Matplotlib and Seaborn.

6 Analyze Data

Use SciPy or statsmodels to conduct appropriate statistical analysis and examine uncertainty.

7 Apply Machine Learning if Appropriate

Use scikit-learn when the project involves prediction, classification, clustering or pattern analysis.

8 Evaluate and Interpret

Evaluate statistical or model results, compare against a baseline and interpret findings within the research context.

9 Communicate and Document

Create a documented notebook containing the methods, code, visualizations, analysis, findings and limitations.

Track 3

Advanced Computational Research

An advanced pathway for projects requiring specialized data science tools and Python libraries for machine learning and deep learning.

Primary Tools Python, JupyterLab, pandas, NumPy, scikit-learn, PyTorch or TensorFlow
1 Collect or Import Data

Collect or import images, text, audio, sensor measurements or other specialized research data.

2 Clean and Validate Data

Check for corrupted files, incorrect labels, duplicate samples, class imbalance and possible data leakage.

3 Prepare and Transform Data

Normalize, encode, resize, tokenize, reshape or extract features from specialized data.

4 Explore Data

Examine representative samples, distributions, class balance, features and patterns before modeling.

5 Visualize Data

Create visualizations that explain the dataset, preprocessing, feature relationships and model behavior.

6 Establish a Baseline

Create a simple statistical or scikit-learn model that advanced models must be compared against.

7 Apply Advanced Modeling if Justified

Use PyTorch or TensorFlow when a neural network or specialized model is scientifically justified.

8 Evaluate and Interpret

Evaluate performance using appropriate validation methods, examine errors and identify bias, leakage and limitations.

9 Communicate and Document

Document the data, preprocessing, model architecture, settings, evaluation, findings and limitations.
